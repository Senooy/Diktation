# Diktation 1.2.2

## Français

- Le nombre d’intervenants peut désormais être corrigé avant de relancer la transcription d’une réunion existante.
- Une analyse qui produit plus de 20 voix en mode automatique est refusée avec une invitation à préciser le nombre de participants. L’audio, les notes et la transcription précédente sont conservés.
- Le nombre choisi est mémorisé pour les prochaines reprises de cette réunion.

## English

- Set the actual speaker count before transcribing an existing meeting again.
- Automatic analyses producing more than 20 voices now request a manual count instead of publishing an unreliable result. Audio, notes and the previous transcript are preserved.
- The selected count is saved for subsequent retries of that meeting.
