# Diktation 1.2.3

## Français

- Les anciennes réunions ayant trop d’intervenants affichent une invitation à corriger leur nombre, sans laisser les champs de noms déborder de la fenêtre.
- La liste des noms défile dans un espace limité pour garder la transcription et les notes visibles.

## English

- Older meetings with excessive speaker counts show recovery guidance without overflowing the window with name fields.
- Speaker names scroll within a bounded area, keeping the transcript and notes visible.
