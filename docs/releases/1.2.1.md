# Diktation 1.2.1

## Français

- Le résultat « Votre logiciel est à jour » n’est plus affiché comme une erreur dans les réglages.
- Une vérification automatique reportée pendant un enregistrement ne déclenche plus de message d’erreur.

## English

- Settings no longer display the successful “You're up to date” result as an error.
- Automatic checks deferred during a recording no longer show an error message.
