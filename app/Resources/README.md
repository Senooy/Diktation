# Ressources visuelles

- `Fonts/Manrope.ttf` : Manrope, distribué sous licence SIL Open Font License, incluse dans `Fonts/OFL.txt`. Source : https://github.com/google/fonts/tree/main/ofl/manrope. Police intégrée au processus, sans installation système ni téléchargement au lancement.
- `Aurora.png` : texture originale générée pour Diktation le 12 novembre 2026, guidée par la palette crème, lilas et prune et le grain de https://www.heypongo.com/. Aucun logo ou portrait de Pongo n’est embarqué.

La référence utilise Svatopluk ; Manrope est l’alternative libre retenue pour l’application. Les icônes utilisent SF Symbols.
